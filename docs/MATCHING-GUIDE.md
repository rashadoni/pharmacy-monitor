# Гайд: как корректировать матчи товаров

## Зачем это нужно

Pharmacy Monitor автоматически находит **один и тот же товар** на 3 сайтах:
например, "Friso Gold 1 800 q" на pharmonline, aptekonline и aloe — это
**один canonical product**, и сравнение цен только тогда корректно.

Автоматический матчер сравнивает имена через fuzzy-алгоритм (порог 90% сходства)
и иногда ошибается:

- **Ложный матч** — склеил 2 *разных* товара (например, "Diazolin Darnitsa" и "Diazolin Farmak"). Сравнение цен будет некорректным.
- **Не сматчил** — не увидел сходство (написания разные). Товар не попадает в "Сравнение цен".

Твоя задача как менеджера — раз в неделю просматривать матчи и корректировать.

## Где это в дашборде

Открой вкладку **🔍 Сравнение цен**. Каждая карточка имеет 3 кнопки внизу:

### ✓ Подтвердить
Зелёная кнопка слева. Нажми когда матч **правильный**. После этого:
- Match помечается `is_manual=True`
- Автоматический matcher больше не будет его пересматчивать
- В метрике "Manual %" растёт твой счётчик

### ✗ Не один товар
Красная кнопка по центру. Нажми когда матч **ложный** — это разные товары.
- Раскроется radio-кнопки выбрать какой Product отвязать
- После подтверждения создаётся **анти-матч** в БД
- Auto-matcher больше не будет склеивать эту пару

### 🔍 Заменить
Нажми когда матч **не правильный, но другой кандидат есть** — например,
система сматчила pharmonline-Diazolin с aloe-Aspirin (ошибка), а правильный
aloe-Diazolin не в матче. Тогда:
- Селектор сайта (`pharmonline`/`aptekonline`/`aloe`)
- Dropdown с unmatched товарами с этого сайта (отсортированы по похожести)
- Выбираешь правильный → старый отвязывается + создаётся анти-матч

## Workflow для первой недели

### День 1 (после первого прогона)
1. Открой **🔍 Сравнение цен**
2. **Min. сайтов: 3** (только товары на всех 3 сайтах)
3. Просмотри 10-20 верхних карточек
4. Каждый матч который **точно правильный** — нажми ✓ Подтвердить
5. **Batch-кнопка** "✓ Подтвердить все (N)" — массовое подтверждение
   всех видимых на странице (используй когда уверен)

### День 2-3
1. **Min. сайтов: 2** — сматченные на хотя бы 2 сайтах
2. Найди ложные матчи → ✗ Не один товар → выбери лишний
3. Найди не-сматченные товары которые ДОЛЖНЫ быть сматчены:
   - Если у клиента есть товар, и ты знаешь что он есть на конкуренте,
     но Сравнение его не показывает — это known limitation auto-matcher'а
   - Можно добавить в **📋 Watchlist** через URL'ы — это даст 100% точный матч

### Через 2 недели
- Метрика **Manual %** на вкладке **📈 Аналитика** должна быть >30%
- Каждый прогон auto-matcher всё точнее (за счёт анти-матчей которые ты создал)
- Можно расслабиться — править только новые матчи

## Где смотреть метрики качества

Вкладка **📈 Аналитика** → блок "🎯 Качество матчинга":

| Метрика | Что значит |
|---|---|
| **Auto-матчей** | Сколько матчей создал автоматический matcher |
| **Manual ✓** | Сколько ты подтвердил вручную (защищены от пересматчивания) |
| **Анти-матчей ✗** | Сколько пар "Не один товар" ты создал |
| **Manual %** | Доля manual / (auto + manual). Растёт со временем |

## Watchlist — точный матчинг через URL

Если категорий много и auto-matcher даёт плохое качество — используй **📋 Watchlist**:

1. Открой Watchlist tab → ➕ Добавить товар
2. Введи имя ("Friso Gold 1 800 g")
3. Вставь **3 URL'а** — точные ссылки на pharmonline, aptekonline, aloe
4. Сохрани
5. На следующем прогоне — auto-match создаст Match-кластер с этими 3 товарами

Это **100% точный матч** через URL, без fuzzy-алгоритма.

## Типовые ошибки

### "Подтвердил матч, а на следующем прогоне он пропал"
- Проверь — возможно на одном из сайтов товар стал out-of-stock
- В Сравнении при `Min. сайтов: 3` он покажется только если есть на всех 3
- Понизь до 2 — увидишь оставшиеся

### "Auto-matcher создаёт много ложных матчей по одинаковым именам"
- Пример: "Vitamin C" — у Bayer и у Solgar разные товары с похожим именем
- Решение: один раз пройдись через ✗ Не один товар + создай анти-матчи
- Auto-matcher запомнит и больше не будет склеивать

### "Manual % всегда 0% — кнопки не работают"
- Проверь что у тебя есть Match'и (вкладка Аналитика → "Сматченных кластеров > 0")
- Если 0 — auto-matcher не нашёл совпадений → нужно использовать Watchlist
- Или подождать пока скрейперы соберут больше данных

## FAQ

**Q: Можно ли отменить ✓ Подтвердить?**
A: Прямо сейчас нет в UI. Через CLI: `pharmacy-monitor matcher unconfirm MATCH_ID`. Или ✗ Не один товар → выбери все Products → Match исчезнет.

**Q: Что если автоматический matcher сматчил товары, которые я только что развязал?**
A: Невозможно — анти-матчи в БД хранятся вечно. Если такое случилось — баг, репортить разработчику.

**Q: Сколько времени занимает корректировка матчей в неделю?**
A: Первая неделя: 30-60 минут (база). Дальше: 5-10 минут/неделя на новые SKU.
