# Профиль «электроника»: Kontakt Home, Irshad, Baku Electronics

Второй клиент того же продукта: **Kontakt Home** (kontakt.az) — клиент,
**Irshad** (irshad.az) и **Baku Electronics** (bakuelectronics.az) — конкуренты.
Решение владельца 2026-11-12.

## Как это будет жить рядом с аптеками

Не тенант в аптечной базе и не второй логин, а **отдельный экземпляр того же
кода**: своя база, свои юниты, свой адрес и вход. Причины — в коде, а не во
вкусе:

- товар в базе уникален по паре «сайт + идентификатор», без тенанта;
- список сайтов `pharmonline / aptekonline / aloe` прошит примерно в пятнадцати
  реестрах (`roi.ALL_SITES`, `product_policy.REQUIRED_CATALOG_SITES`,
  `storage.FULL_CATALOG_SITES`, `cadence`, …) и больше тысячи раз в коде;
- доверие ценам, рекомендации и health требуют свежего сбора **всех** сайтов из
  списка: упавший сбор электроники закрывал бы рекомендации аптечному клиенту;
- сопоставление товаров аптечное (доза, форма, страна); электронике нужно
  сопоставление по модели.

Экземпляр выбирает набор сайтов профилем. Профиль по умолчанию — аптеки:
аптечный прод работает как работал.

## Сборщики

Все три читают сайт обычными HTTP-запросами, без браузера
(`src/scrapers/http_catalog.py`). Формы ответов сняты с живых сайтов 2026-11-12.

| | Kontakt Home | Irshad | Baku Electronics |
|---|---|---|---|
| Имя сайта в коде | `kontakt` | `irshad` | `bakuelectronics` |
| Откуда каталог | `/<категория>.data` (данные витрины, turbo-stream) | `/az/list-products/<раздел>?page=N` (вёрстка карточек) | `/_next/data/<buildId>/az/catalog/<раздел>.json` |
| Товаров на страницу | 16 | 9 карточек | 18 |
| Сайт называет число товаров | да | нет | да |
| Идентификатор товара | `sku` (артикул) | номер товара на сайте | `product_code` |
| Наличие | признак «в наличии» | метка «Stokda var» | остаток числом |
| С адреса дата-центра | проверка Cloudflare (403) | открывается | блокировка Cloudflare (403) |
| Пауза между запросами | 2 с | 30 с (просит robots.txt) | 2 с |
| Страница на проводе | ≈23 КБ | ≈6 КБ | ≈12 КБ |

Что считается полным каталогом (`discover_categories`):

- **Kontakt Home** — все категории-списки (`type: CATEGORY`); сборщик находит
  их, спускаясь от меню сайта по витринам разделов (`type: SUBCATEGORY`).
- **Baku Electronics** — разделы верхнего уровня: список раздела включает
  товары всех подразделов (раздел tv-audio-video и объединение 19 его
  подразделов совпали товар в товар, 371 и 371). Раздел, чья страница на сайте
  сломана (telefonlar-qadcetler отвечал 502), заменяется подразделами.
- **Irshad** — разделы первого уровня из меню (список foto-texnika совпал с
  объединением его подразделов, 16 и 16). Уценка и акции (`outlet`,
  `kampaniyalar`) не обходятся: это те же товары.

Проход категории цельный: неполный проход повторяется с начала, попытки не
склеиваются. Там, где сайт называет число товаров, проход полон, только когда
собрано ровно столько разных товаров; у Irshad — когда список дошёл до страницы
без «показать ещё», без ошибок разбора и без повтора товара на двух страницах.

## Проба с живого сайта

Ничего не пишет в базу, печатает прочитанное:

    python -m src.scrapers.electronics --site irshad --discover
    python -m src.scrapers.electronics --site irshad --category foto-texnika --limit 20

Kontakt Home и Baku Electronics с сервера отвечают только через прокси: те же
переменные Decodo, что у aptekonline (`DECODO_USERNAME`, `DECODO_PASSWORD`), и
сайт в `DECODO_SITES`. Значения — в `/etc/pharmacy-monitor/env`, сюда не пишутся.

## Что проверено и что нет (2026-11-12)

- **Irshad** — сборщик исполнен против живого сайта с dev-бокса: раздел
  foto-texnika и пять его подразделов, все проходы полные, цены, скидки и
  наличие совпали с карточками; карточка с выбором цвета отдаёт все цвета.
- **Kontakt Home и Baku Electronics** — сборщики против живого сайта **не
  исполнялись**: без прокси сайт их не пускает, а ключи прокси лежат на проде.
  Формы ответов, разбивка на страницы, признак полноты раздела и поведение
  сломанного раздела сняты с живых сайтов в браузере; тесты повторяют эти формы.
  Первый запуск через прокси — проверка на живом сайте.
- Пропускает ли Decodo оба сайта, не проверено. У Kontakt Home проверка
  Cloudflare («Just a moment»), у Baku Electronics — жёсткая блокировка адреса.
- Размер каталогов: у Baku Electronics около 12 тысяч товаров (сумма по
  разделам), у Irshad около 5 тысяч (карта сайта); у Kontakt Home не считали.
- Включает ли список категории Kontakt Home товары вложенных категорий, не
  проверено; вложенная категория-список из обхода не выбрасывается.
- Цена: у Irshad и Baku Electronics одна цена на товар плюс скидка. Цену «в
  рассрочку» и подарочные условия сборщики не читают.
